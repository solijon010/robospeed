# Robospeed — Claude uchun qoidalar

## Branch strategiyasi

- **`main`** — production branch. To'g'ridan-to'g'ri push qilinmaydi.
- **`test`** — barcha o'zgarishlar avval shu branchga PR orqali yuboriladi.

## Push qilish tartibi

1. O'zgarishlarni `test` branchiga PR sifatida yubor.
2. Hech qachon `main` branchiga to'g'ridan-to'g'ri push qilma.
3. `test` branchga merge qilish va `test` → `main` merge qilish faqat repo egasi tomonidan amalga oshiriladi.

## Commit xabarlari

- Commit xabarlarida "Co-authored by Claude", "Generated by Claude" yoki shunga o'xshash Claude tomonidan qo'shilgan iboralar **bo'lmasligi kerak**.
- Commit xabarlari qisqa va aniq bo'lsin: nima o'zgartirilganini ko'rsatsin.
- `Co-Authored-By` yoki boshqa avtomatik trailerlar qo'shilmasin.

## PR yuborish

- PR sarlavhasi o'zgartirilgan funksionallikni qisqacha ifodalashi kerak.
- PR faqat `test` branchiga yuboriladi, hech qachon `main` ga emas.

## Umumiy

- Maxfiy ma'lumotlar (`.env`, API kalitlar) hech qachon commitga qo'shilmasin.
- Har bir PR bitta mantiqiy o'zgarishni o'z ichiga olsin.
